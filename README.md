# 🌑 H. P. Lovecraft — O Universo do Horror Cósmico

Um projeto desenvolvido em **Vue.js + Vite + TypeScript** inspirado no universo literário de **H. P. Lovecraft** e no conceito de Horror Cósmico.

O site apresenta informações sobre o autor, suas principais obras e algumas das entidades mais importantes do Mythos de Cthulhu, utilizando uma interface sombria e inspirada na atmosfera das obras de Lovecraft.

## 🧠 Sobre o Projeto

Este projeto foi desenvolvido como uma aplicação web utilizando **Vue.js**, com o objetivo de praticar conceitos de desenvolvimento Front-End, organização de componentes, estilização e gerenciamento de estado.

A temática escolhida foi o universo de **H. P. Lovecraft**, explorando elementos do Horror Cósmico e do Mythos de Cthulhu.

---

## 🕯️ Conteúdo

O site apresenta diferentes seções:

- 👁️ **Hero** — apresentação temática do universo de Lovecraft
- 📖 **Autor** — informações sobre H. P. Lovecraft
- 📚 **Obras** — principais obras literárias
- 🐙 **Mythos** — entidades do universo lovecraftiano
- 🌑 **Final** — encerramento da experiência
- ⚫ **Footer** — informações do projeto

### 📚 Obras apresentadas

- *The Call of Cthulhu* — 1926
- *The Colour Out of Space* — 1927
- *The Dunwich Horror* — 1928
- *The Shadow over Innsmouth* — 1936
- *At the Mountains of Madness* — 1936
- *The Shadow Out of Time* — 1936

### 👁️ Entidades

- Cthulhu
- Yog-Sothoth
- Azathoth
- Nyarlathotep
